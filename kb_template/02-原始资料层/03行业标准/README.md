# 行业标准原文存放位置

这里存放行业标准的全文（Markdown格式）。行业标准通过 `标准库#下载` 命令调用爬虫下载后自动落在这里；
企业标准/其他通过本地文件转换（`标准库#转换`）或人工放入原文件后转换。

这一层的文件本身不需要人工维护内容，agent核验时会读取这里的原文摘录引用；Wiki层笔记通过链接
指向这里的具体文件，不要反过来在这层文件里塞核验结论——结论都在Wiki层。


## 关于文件夹组织方式

这层可以按任意深度的子文件夹组织，比如按发布年份分、按专业领域分，或者把整份电子版制度汇编原样放进来
保留其原有的文件夹结构——都可以，不要求把文件全部拍平放在同一层。agent检索这一层时会递归遍历所有
子文件夹，不会因为放得深一层就找不到。如果实际使用中发现某些深层文件夹里的内容"有时候识别不出来"，
这属于bug，应该反馈调整agent的检索指令，而不是让用户把文件重新挪成扁平结构去将就它。


## 关于"待查文件（不引用）"文件夹

如果你把"待查文件（不引用）"这个文件夹放在这一层（或者这一层下面任意深度的子文件夹里），
agent检索时会**结构性跳过**这个文件夹，不会把里面的内容当成正式标准/制度去引用或摘录——
包括常规问答、巡查检查、专项工作包生成这几个智能体做"企业标准全量搜索"这类不经过滤的全量摘录时，也会排除这个文件夹。这个排除只看文件夹名字，不管它嵌套在哪个位置，放这一层
下面任何地方都能正确排除。
