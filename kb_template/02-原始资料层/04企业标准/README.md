# 企业标准原文存放位置

这里存放集团、平台公司、本企业的制度/标准全文（Markdown格式），按发布主体分子文件夹：
`示例集团集团标准`、`示例电力平台标准`、`清洁能源平台制度`、`示例集团数产平台制度`、`公司标准` 等。
通过 `标准库#下载` 或 `标准库#转换` 落入，也可把整份制度汇编按原文件夹结构原样放入。

这一层的文件本身不需要人工维护内容，agent核验时会读取这里的原文摘录引用；Wiki层笔记通过链接
指向这里的具体文件，不要反过来在这层文件里塞核验结论——结论都在Wiki层。

## 关于文件夹组织方式

可以按任意深度的子文件夹组织，不要求拍平。agent检索这一层时会递归遍历所有子文件夹。

## 关于"待查文件（不引用）"文件夹

这一层（或任意深度的子文件夹）里名为"待查文件（不引用）"的文件夹，agent检索时会**结构性跳过**，
不会把里面的内容当成正式制度引用或摘录。排除只看文件夹名字，不管嵌套在哪一层。
