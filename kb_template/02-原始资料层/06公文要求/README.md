# 06公文要求

上级发文、集团/公司管理要求、公文格式基准都放这里。分支 A/B/C/D/F/G 的「R03b 依据来源」「R15 领导报送要求」「R00c 公文依据补充」都指向本目录，**这里的文件可作依据使用**。分支 D 会把本目录新增的 docx/pdf 主动转 md 并 upsert 进 RAG 的「公文」层。

## 随包提供的格式示例

| 文件 | 用途 |
|:---|:---|
| `公文格式示例_制度规范卡.docx` | 制度全量摘录卡（制度规范卡）的版式基准：抬头、声明框、条款表、页脚。分支 E 生成规范卡时对照此文件 |
| `公文格式示例_工作相关考核标准.docx` | 考核/验收标准摘录件的版式基准：考核条款表、依据列、免责声明。分支 E 生成考核标准时对照 |

两份都是**空壳示例**（正文为示例条款，企业名已脱敏为「示例电力」），照抄版式即可，内容按实际项目替换。字体、页边距、段落间距与 `01-Wiki层/00-必读/共享操作模板.md` 第6节一致。

## 需要自备

真正可作依据的上位文件（集团的部署文件、行业主管部门的规范性文件、本公司现行管理制度）有版权与保密属性，仓库不提供。放进来后：

1. docx/pdf 直接放入本目录（可建子文件夹）；
2. 分支 D 发现新增文件会自动转 md 并入库；也可手动执行 `python "04-脚本代码/04 D标准库管理/ingest/"` 下的入库脚本；
3. 未入库的文件检索不到，等于没放——放完记得确认索引已更新。

## 使用注意

- 本目录的文件**必须先辨发文平台**：本集团/本公司的文可直接引用；其他平台（行业协会、兄弟单位、地方主管部门）的文要结合适用范围判断后再引用。
- 引用时写明发文机关、文号、成文日期，与 `01-Wiki层/00-必读/智能体公共规则.md` 的引用格式一致。
- 本目录不存放标准原文（标准放 `00国家标准`/`03行业标准`），也不存放隐患图集（放 `05问题分析参考清单`）。
