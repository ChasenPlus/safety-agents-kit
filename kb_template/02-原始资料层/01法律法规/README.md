# 法律法规原文存放位置

这里存放法律、行政法规、地方法规的全文（Markdown格式）。通过 `标准库#下载` 命令调用爬虫下载后自动落在这里；
纸质件或本地PDF通过 `标准库#转换` 转成 md 后放入。

这一层的文件本身不需要人工维护内容，agent核验时会读取这里的原文摘录引用；Wiki层笔记通过链接
指向这里的具体文件，不要反过来在这层文件里塞核验结论——结论都在Wiki层。

## 关于文件夹组织方式

可以按任意深度的子文件夹组织（按年份、按专业、按发文机关均可）。agent检索这一层时会递归遍历所有子文件夹，
不会因为放得深一层就找不到。

## 关于"待查文件（不引用）"文件夹

这一层（或任意深度的子文件夹）里名为"待查文件（不引用）"的文件夹，agent检索时会**结构性跳过**，
不会把里面的内容当成正式依据引用或摘录。排除只看文件夹名字，不管嵌套在哪一层。
