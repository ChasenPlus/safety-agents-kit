# 00-导航层

按「业务主题 / 工作类型 / 标准层级」三个入口组织索引，作用是让分支先用少量上下文定位到该读哪篇笔记，而不是一上来做全库检索。

仓库只保留目录结构，索引文件需要按自己的业务补充：

| 目录 | 放什么 | 建议内容 |
|:---|:---|:---|
| `按业务主题/` | 电气、起重、消防、有限空间、危大工程等主题索引 | 一行一个主题：主题 → 相关制度 → 关键标准条款 |
| `按工作类型/` | 检查、修订、方案、培训、定责等任务索引 | 一行一个任务：任务 → 触发条件 → 必读 Wiki 笔记 |
| `按标准层级/` | 法律、行政法规、部门规章、国标、行标、企标的归属说明 | 一行一个层级：层级 → 适用范围 → 存放目录 |

没有索引文件时，分支会退回 `sak-rag` 的语义检索，结果不受影响，只是首轮定位会慢一些。
