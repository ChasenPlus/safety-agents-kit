# 03-输出层

所有交付物落盘的地方。目录按分支职责划分，分支提示词里的输出路径默认指向这里。

| 目录 | 归属分支 | 内容 |
|:---|:---:|:---|
| `巡查检查/` | B | 检查问题清单、整改通知单 |
| `出报告/` | B | 报告模板与模板绑定表（`Template/<类别>/`） |
| `制度修订编制/` | C | 修订建议书、制度自查台账 |
| `工作包/` | E | 安全/技术交底、应急处置卡、考核标准、规范卡、培训卡 |
| `专项方案模板库/` | F | 施工组织方案（十章）、危大工程专项方案（九章） |
| `安全报告/` | G | 周报、月报、季度报、安委会材料 |

## 随包提供的模板（可直接用，路径已对齐提示词）

| 文件 | 对应分支 / 用途 |
|:---|:---|
| `制度修订编制/示例电力制度自查台账.xlsx` | C / H：企业标准层缺口台账。两列已知结构：`汇总`（制度编号、累计问题数、建议书路径、确认状态）+ `{编号}_{制度名称}` 明细表（记录日期、触发问题、缺口类型、建议补充方向、上位依据、状态）。H 的 R06b 与 C 的台账回写直接指向本文件 |
| `制度修订编制/制度修订建议书_格式示例.docx` | C：修订建议书的版式基准（安全声明、版本历史表、修订前后对照、审批链）。生成新建议书时复制本文件再填充，不要直接改它 |
| `专项方案模板库/四措两案（施工组织方案）_规范模板.docx` | F：项目级施工组织方案（四措两案）空模板，章节结构与 F 提示词的十章模板一致 |
| `专项方案模板库/四措两案（施工组织方案）_实例_配电室改造.docx` | F：已填写的完整实例（配电室整体迁建，约 4.7 万字），用于对齐章节颗粒度与措辞，**不是可复制的答案** |

表单类模板在知识库根目录：[企业标准体系目录.xlsx](../企业标准体系目录.xlsx)（`sak-private` 的 `match_regulation` 与 `sak doctor` 都读它）；
公文依据类模板在 `02-原始资料层/06公文要求/`。

## 缺失时的降级

上述模板缺失不影响流程启动，但输出会退化：

- 台账缺失 → H 无法持久化条目，只能在回复里内联表格并标注「未持久化-请手动补录」；C 读不到历史缺口，会重复提问。
- 建议书格式示例缺失 → C 现场用 `python-docx` 搭结构，字体、页边距、对照色块可能与示例不一致，需人工校版。
- 四措两案模板缺失 → F 按提示词内置章节骨架直接生成，缺少页眉页脚、报审表等成稿要素。

约定：

- 报告类交付物先复制模板再填写，不要直接改模板文件。
- 文件名带日期与版本，例如 `2026-11-11_季度报_v1.docx`。
- `出报告/Template/` 下的模板与 `模板绑定.py` 需要自己准备；缺失时分支会按内置默认结构直接生成。
- 台账模板里的示例行（2112《安全文化建设管理规定》）只用于示范列结构，正式使用前清空 `{编号}_{制度名称}` 明细表与 `汇总` 的数据行。
