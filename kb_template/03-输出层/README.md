# 03-输出层

所有交付物落盘的地方。目录按分支职责划分，分支提示词里的输出路径默认指向这里。

| 目录 | 归属分支 | 内容 |
|:---|:---:|:---|
| `巡查检查/` | B | 检查问题清单、整改通知单 |
| `出报告/` | B | 报告模板与模板绑定表（`Template/<类别>/`） |
| `制度修订编制/` | C | 修订建议书、制度自查台账 |
| `工作包/` | E | 安全/技术交底、应急处置卡、考核标准、规范卡、培训卡 |
| `专项方案模板库/` | F | 施工组织方案（十章）、危大工程专项方案（九章） |
| `安全报告/` | G | 周报、月报、季度报、安委会材料 |

约定：

- 报告类交付物先复制模板再填写，不要直接改模板文件。
- 文件名带日期与版本，例如 `2026-11-11_季度报_v1.docx`。
- `Template/` 下的模板与 `模板绑定.py` 需要自己准备；缺失时分支会按内置默认结构直接生成。
