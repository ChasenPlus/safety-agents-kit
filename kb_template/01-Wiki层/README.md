# 01-Wiki 层说明

这一层是**分支的「经验与规则」库**：各分支开工时通过 `sak-rag` 检索，把命中的笔记拼进上下文。
代码仓库只带**公共规则**（`00-必读/`），其余笔记属于使用方自有的业务经验，需要自己补。

## 随包提供

| 文件 | 用途 | 谁必读 |
|:---|:---|:---|
| `00-必读/智能体公共规则.md` | 工具权限、跨分支协作、通用铁律、写作与交付规范 | 全部分支 |
| `00-必读/规则索引-按场景查.md` | 场景 → 规则条目 的索引，避免整篇塞进上下文 | A/B/E/F |
| `00-必读/共享操作模板.md` | 工作包、方案、报告类任务的通用检索与产出模板 | B/E/F/G |

## 命名建议

- 用「主题-内容.md」，避免只用日期当文件名，语义检索更容易召回。
- 每篇开头写一段 3～5 行的摘要，切块后摘要是最容易被召回的片段。
- 表格优先于长段落；一列一个字段，不要合并单元格。

## 与索引的关系

`server/rag/rag_core.py` 默认把知识库根目录下的 `01-Wiki层/` 纳入检索。
新增或修改笔记后执行一次重建索引（见 [docs/deployment.md](../../docs/deployment.md)），否则改动不会被召回。
